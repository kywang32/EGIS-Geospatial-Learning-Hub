# Optional restricted EGIS PDF library

This folder intentionally contains **no** course PDF files in the public GitHub repository.

The author distributes the 14 EGIS lesson/practical PDF files separately upon approved request. See [`../../../COURSE-MATERIALS-ACCESS.md`](../../../COURSE-MATERIALS-ACCESS.md) and the repository README. (From this folder, the repository root is `../../../`.)

Once approved, place the 14 PDFs **here**, using the exact filenames listed in `../lookup/knowledge-index.json`. Do **not** commit them, open a pull request containing them, or upload them to any public release. The public Skill operates without them, with reduced course-specific citation support.
